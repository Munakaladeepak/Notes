# Roadmap

## Phase 1 — Core foundations

Complete [[01 - Programming Logic/README|Programming Logic]] and [[02 - OOP/README|OOP]]. You should be able to trace conditions, loops, arrays, complexity, classes, objects, and the four OOP pillars.

## Phase 2 — Primary test technologies

Study [[03 - Core Java/README|Core Java]], [[04 - PHP/README|PHP]], and [[05 - MySQL and SQL/README|MySQL and SQL]]. These map directly to the required skills and are the highest-value topics.

## Phase 3 — Web and full-stack layer

Study [[07 - Web Technologies/README|Web Technologies]], [[08 - JavaScript/README|JavaScript]], [[09 - Node and Express/README|Node and Express]], and [[10 - React/README|React]]. Then connect them through [[11 - REST and HTTP/README|REST and HTTP]].

## Phase 4 — Engineering practices

Study [[13 - Testing and Debugging/README|Testing and Debugging]], [[14 - Git/README|Git]], [[17 - Security/README|Security]], and [[12 - MVC and Frameworks/README|MVC and Frameworks]].

## Phase 5 — Good-to-have topics

Finish [[06 - MongoDB/README|MongoDB]], [[15 - Cloud and Deployment/README|Cloud and Deployment]], and [[16 - Figma and UI UX/README|Figma and UI/UX]].

## Study loop for every topic

1. Read the concept note.
2. Write one example in your own words.
3. Solve or trace the examples without looking.
4. Mark the linked checklist item complete.
5. Review the related [[00 - Start Here/Exam Traps|Exam Traps]].
6. Take a timed test after finishing a phase.
