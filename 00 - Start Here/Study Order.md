## Why this order?

Java and OOP establish the programming model. SQL and PHP cover the strongest required-skill area. Web, JavaScript, REST, React, Node, and MongoDB then show how a CRM full-stack application fits together. Testing, Git, security, cloud, and Figma complete the good-to-have engineering layer.

## Priority key

- **Very high:** likely to produce many direct concept and code questions.
- **High:** required or common supporting knowledge.
- **Medium:** good-to-have framework and engineering knowledge.
- **Low:** likely to be lighter awareness questions.
